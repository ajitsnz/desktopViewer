Steps to start sharing:

  1. Run signaling server: npm run signal (or use existing URL)
  2. Enter the server URL below and click Connect
  3. Select a source from the list to start streaming
  4. Open the app on another machine, connect to same URL to view

You can close this panel once you connect.
